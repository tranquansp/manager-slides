# Changelog

## 0.1.0 — 2026-08-19

Initial release.

- Two skills: `manager-slide-generate` and `manager-slide-redesign`.
- Shared engine: measured design constants (management slice — 4 audiences × 5 purposes),
  8 page archetypes, styling presets, and the render → screenshot → self-inspect loop.
- Four output engines: HTML deck (16:9), HTML report, Typst, PPTX.
- New 16:9 `deck.html` shell with `.slide` / `window.go(i)` for clean PDF export.
- Design rules carried from the `report-designer` research corpus (236 reports); packaging
  and brief-first discipline from the `taste-skill` architecture.
- Brand-agnostic: no fixed brand; a user brand guideline overrides styling tokens.
